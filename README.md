J.P. Morgan Advanced Software Engineering Simulation
This repository contains my solutions for the J.P. Morgan Advanced Software Engineering virtual experience program on Forage.

🔹 Overview
The simulation replicates tasks a Software Engineer might face at J.P. Morgan. I completed five tasks involving Java, Maven, Spring Boot, Apache Kafka, SQL (H2), and REST APIs.

🛠 Tasks Completed
Project Setup – Configured Maven project and IDE.
Kafka Integration – Set up producer/consumer for messaging.
H2 Database – Connected in-memory DB and implemented persistence logic.
External REST API Integration – Integrated Spring app with a public API.
Exposed REST API – Designed and implemented custom REST endpoints.
🚀 Skills Practiced
Backend development with Spring Boot
Apache Kafka for real-time messaging
SQL (H2 Database) integration
REST API design & consumption
Using Maven for dependency management
